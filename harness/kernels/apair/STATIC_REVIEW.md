# Independent static review

Reviewed the candidate `humming_apair.py` and the `humming_nvsc.py` dispatch diff against the c41 baseline and the pinned Humming 4351 source. No definite static blocker was identified. This is not a proof of correctness or evidence that the candidate is selected in production.

- The N128, eight-warp mapping and PFUP mask use four N warps. The tail flag reuses shared word 63 only after the second row-validity ballot is combined, followed by the existing CTA barrier. The dummy tail still participates in the pipeline and barriers.
- The B loader selects the original N1856/K2688 strides, zero-fills the missing half of the last N tile using a legal source pointer, and advances once per K32 stage. The NVSC loader addresses two independent 96-byte records in the original 29-tile-per-expert layout, advances each pointer in K order, and zero-fills the missing record. The indexed writer keeps the N1856 row stride and masks each eight-element store against that boundary.
- Source inspection indicates the producer and epilogue hold the new concrete loader/writer types, so the derived `seek`, `load`, and `write` methods are the calls selected by those pipelines. The 256-thread A staging corresponds to the original two 128-thread load iterations for the reviewed configuration.
- The dispatch is restricted to the stated shape, device, NVSC and PFUP conditions. A cold graph capture takes the existing path; preparation failures occur before the candidate launch and fall back. Resource checks and header pins are admission guards, not numerical or speed tests. Newly added E4M3, batch-invariance and arithmetic-mode assertions narrow the accepted configuration; the named flags exist in the pinned configuration source.

No candidate code was imported, parsed, compiled, or run locally for this review. Installed header and Python byte identities have not been established by this review. Compilation, PTX zero-fill behavior, graph behavior, actual path activation, BF16 correctness, and whole-bundle performance remain to be established by the official remote run. Successful fallback or an aggregate score alone would not establish activation or individual component causality.
