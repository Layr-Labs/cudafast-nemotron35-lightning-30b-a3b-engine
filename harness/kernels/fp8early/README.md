# Optional FP8 last-reader stage release

Derived from the complete highest verified1faceed1-7860-4e8d-b734-96600d6629aa FP8ws source, including the in_proj/out_proj coverage ofa7707aa4-f2fa-40b5-b52e-adfdd94825a9 and original8b406fa2-8fbf-4867-a9fb-7a8b40915ae3 kernel. Original fp8ws package stays byte-identical and remains the reference/fallback. Every execution, compilation and qualification is official remote work only.

The new library changes shared-stage ownership timing, with the same eight compute warps, two default shared stages, persistent grid, tile geometry and original numerical operations. Fill the original stages at startup. After the final K32 fragment loads of a K128 stage, each warp executes syncwarp and its existing empty-barrier arrival. Thread0 waits on that original all-eight-reader barrier and issues iteration g+ST into the released stage before its final register MMAs and epilogue. Last-fragment values are already in registers. Output publication and each output's ascending K chain remain unchanged. No shared read occurs after release, no stage is released twice, and the original full-barrier phase formula is preserved.

This intends to overlap future TMA completion with the tail's register math/epilogue; it does not reduce weight bytes or arithmetic. It may increase control/fragment liveness, register pressure or spills, or delay the producing warp enough to lose. No compiler resource, activation, occupancy, stall or speed result is known yet. Inherited timing comments in the copied CUDA file describe the old parent only.

The independent optional build leaves the original fp8ws library untouched even if compilation fails. A per-weight admission runs only after the original pack inversion and CUTLASS word admission. It compares original and early C ABIs with exact-shape private input/scalar/output guards, full output bits over the parent's five FP8 input patterns and all scale pairs, eight distinct graph outputs with changing input/scalar contents, readonly weights/packs/inputs/scalars, and alternating warm/64MiB-pressure CUDA-event timings. Median and summed latency ratios must be below0.99 and no case at or above1.01. Failure/refusal retains the original. No private input/output/graph or closure persists; decisions retain immutable weight/pack owners only. FP8WS_EARLY_RELEASE=0 disables it.

Primary instruction references: [PTX ldmatrix](https://docs.nvidia.com/cuda/parallel-thread-execution/#warp-level-matrix-instructions-ldmatrix), [mbarrier.arrive](https://docs.nvidia.com/cuda/parallel-thread-execution/#parallel-synchronization-and-communication-instructions-mbarrier-arrive), [mbarrier.try_wait](https://docs.nvidia.com/cuda/parallel-thread-execution/#parallel-synchronization-and-communication-instructions-mbarrier-try-wait).
